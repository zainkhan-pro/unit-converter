# ZETA Integrated Development Phases

The repository is organized as one integrated product rather than ten disconnected demos.

1. **Foundation:** Next.js, TypeScript, ESLint, Prettier, secure headers, responsive CSS.
2. **Conversion Engine:** declarative definitions and deterministic conversion math.
3. **UI:** premium converter, category navigation, swap, formulas and all-units view.
4. **Smart Parser:** rule-based natural-language unit parsing and aliases.
5. **Currency:** server API route, live provider adapter, caching and explicit unavailable state.
6. **History/Favorites:** LocalStorage with delete/clear/reuse-ready records.
7. **Calculators:** BMI, percentage, discount, tip plus extensible pure calculator library.
8. **PWA:** installable manifest and service-worker shell caching.
9. **Testing:** Vitest conversion/parser coverage; run lint/build/test before release.
10. **Production Deployment:** configure provider/database secrets, HTTPS, real domain, monitoring, final accessibility and device QA.
